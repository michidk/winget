# WinGet

My WinGet packages.

Built with GitHub actions using [winget-updater](https://github.com/michidk/winget-updater) and [run-komac](https://github.com/michidk/run-komac/).

All package submissions and branch cleanup use the shared
[`michidk-contrib/winget-pkgs`](https://github.com/michidk-contrib/winget-pkgs) fork.
New package manifests belong in that fork and must be accepted upstream before
this repository can maintain them through the updater workflow.
